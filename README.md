# Xbox 360 Pocket Library 🎮
Личная интерактивная библиотека дисков Xbox 360 для iPhone. Основана на финальном дизайне Gemini и адаптирована для мобильного использования.

## Как опубликовать приложение
1. В этом репозитории выбери **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**, ветку **main**, папку **/(root)** и нажми **Save**.
3. Когда GitHub завершит публикацию, открой **https://viperbeth.github.io/xbox-pocket-library/**.
4. На iPhone открой ссылку **в Safari** → **Поделиться** → **На экран «Домой»** → **Добавить**. Если появится переключатель «Открывать как веб-приложение», включи его.

## Как устроены файлы
- `index.html`: приложение и все необходимые стили (никакого дополнительного CSS для запуска не требуется).
- `manifest.webmanifest`: название, режим открытия и иконки PWA.
- `sw.js`: Service Worker, кеширующий оболочку приложения и открытые обложки.
- `icons/`: иконка для iPhone и масштабируемая иконка.
- `README.md`: инструкция.

## Где хранятся игры и изменения
Добавленные игры, статусы, отметки о нечитаемых дисках, избранное и новые фотографии сохраняются **в браузерном хранилище этого устройства** (IndexedDB; ограниченный fallback — localStorage). GitHub НЕ сохраняет и НЕ синхронизирует пользовательскую коллекцию между устройствами.

**Важно:** перед сменой телефона, очисткой Safari или сменой адреса приложения открой резервные копии в приложении и выгрузи JSON в «Файлы» или iCloud Drive. В другом браузере/на другом устройстве восстанови JSON через импорт.

Обложки из Wikimedia/других внешних источников требуют доступности этих сайтов. Офлайн они появятся только после кэширования; для гарантированной офлайн-работы всех обложек в дальнейшем потребуются локальные изображения.

## Безопасность
Репозиторий публичный. Не добавляй сюда личные резервные копии JSON, пароли, ключи API или приватные фотографии. Файл приложения не содержит серверной синхронизации и не требует платной Apple Developer Program.

## Проверка на iPhone
Попробуй перелистнуть Cover Flow, повернуть и открыть коробку пальцем, изменить состояние диска на «Не читается», добавить/изменить/удалить пробную игру, перезапустить приложение, проверить сохранения и экспорт JSON. После первого запуска онлайн проверь открытие приложения без сети.
